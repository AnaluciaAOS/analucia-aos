01 · The idea

Three roles. One of them is you.

AI agents are fast and sometimes wrong. The loop gives each party one job, so speed never replaces judgment.

  • Owner · you

    Decides and signs

    Sets the goal, approves what matters, and is the only one who can close a risky piece of work.

  • Director

    Plans and checks

    Turns your intent into small, bounded orders and verifies the result against the disk, not against a summary.

  • Executor

    Builds, in a box

    The coding agent does the work inside limits: a budget, a scope, and files it is not allowed to touch.

Rule of the loop:an agent can propose and build. Only the owner can approve and close.

02 · The loop

Six steps. Every one leaves a trace.

  1. Step 1

    You say what you want, in your words.

    For example, you write “add a contact page”. Nothing else is needed from you yet.

  2. Step 2

    The director writes a small, bounded order with a budget.

    The order names its budget in minutes and attempts, its risk level and the checks that will prove it is done.

  3. Step 3

    The executor works inside the limits of that order.

    If the agent tries to edit an order or its checks, the tool blocks the edit before it happens, as long as the plugin is active in the project folder.

  4. Step 4

    Automatic checks run. Nobody grades their own work.

    The checks were written by the director, not by the agent; a high-risk order runs them twice.

  5. Step 5

    Results are saved as files you can open.

    The report keeps the raw output of every check, next to the order it belongs to.

  6. Step 6

    You close it, or you send it back with a note.

    You type CLOSE for work that passed, or comment on a document; your note reaches the agent.

Tamper-evident log.Every step is written to a chained record. If anyone edits the past, the chain breaks and the tool tells you.

  • Interrupted? Pick up where it stopped; the tool shows what was left open.

  • Too risky? Higher-risk orders need your typed confirmation.

  • Lost a laptop? The project rebuilds from the repository.

04 · Get started

Four steps. Then your first hour.

Before you start

About 10 to 15 minutes if you install only these.

  • Git, the program that keeps the project's history. Check: git --version
  • Node.js LTS, a free program the Loop uses internally, installed once. On nodejs.org, on Windows choose the “Windows Installer (.msi)” button and accept the defaults; on macOS use the macOS installer, and on Linux your system's package or the prebuilt download. Check: node --version
  • Claude Code, signed in.
  • The Claude desktop app, only if you want a chat with a connected folder.
  • An empty project folder.

You do not need Chocolatey, Visual Studio, Python or Docker.

  1. Add the pluginclaude plugin marketplace add AnaluciaAOS/analucia-aos
  2. Install itclaude plugin install analucia@analucia-aos --scope project
  3. Open Claude Code in that same folderNot in a subfolder: the plugin loads its guards only in the folder where it was installed. In a folder that is not set up yet, the first message says that the plugin is installed and the folder is not set up, and gives the exact aos init command to run. “Status:” appears only in a folder already set up.
  4. Answer the setupaos init asks 15 closed questions in 3 blocks, with your progress and the time left: about 5 minutes. The first question chooses the language. A summary comes at the end, and nothing is written until you type CONFIRM.
